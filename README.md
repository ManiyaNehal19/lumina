# Lumina 🌟

Lumina is a modern web app that generates **flashcards** from your topics and notes, stores them in a database, and lets you access them through a sleek, user-friendly interface. Perfect for learning and revision.  

---

## Live Demo

Access Lumina here: (https://lumina-ten-beta.vercel.app/) 🌐

---

## Features

- 📝 **Flashcard Generation** – Automatically create flashcards from topics or notes using AI.  
- 💾 **Storage** – Save and organize your flashcards in MongoDB.  
- ⚡ **Full-stack Modern UI** – Built with **Next.js**, **Tailwind CSS**, and **TypeScript**.  
- 🤖 **AI Integration** – Powered by **Gemini API** for smart content creation.  
- 🌐 **Accessible Anywhere** – Fully responsive on desktop and mobile.  

---

## Tech Stack

- **Frontend & Backend:** Next.js  
- **Styling:** Tailwind CSS  
- **Language:** TypeScript  
- **Database:** MongoDB  
- **AI Integration:** Gemini API
